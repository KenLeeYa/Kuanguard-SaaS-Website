- 石墨藍 `#18212F` 主文字、藍色 `#315ED1` 強調、`#F8FAFC` 淺底、白色產品內容區。深色資訊區用於說明資料權限及服務紀錄。

## 驗證與範圍

使用 TypeScript、14 項前端測試、Next 正式建置、實際 HTTP/SSR 與靜態資源檢查。額外確認原點餐首頁 component 及 commerce.css 位元組保留、公司與產品的 canonical/metadata、主要連結與 BFF health。修正不存在的產品 URL 被 Next 串流為 200 的情況：路由層先回真正的 404，並增加 regression test。收據見 [corporate-website-20260910.json](evidence/corporate-website-20260910.json)。

此變更沒有 database migration、seed、重跑歷史 Phase、改動 Partner 權限、付款、寄信或公網 DNS。現有 Docker/Partner receipt 對應先前 `560c50c` 版本；本輪更新本機 Next 正式 build 與 Git 原始碼，不把舊映像收據當作新版視覺的驗證。

先前管理政策拒絕瀏覽器自動化，本輪沿用該限制，不改用其他瀏覽器自動化工具繞過。HTTP/SSR 通過不代表已完成 viewport 截圖、視覺或完整鍵盤實機驗收；可在本機頁面直接檢視這次提案。
