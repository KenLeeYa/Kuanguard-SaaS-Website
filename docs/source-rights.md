# 來源與權利清冊

| 內容 | 來源／處理 | 可用界線 |
| --- | --- | --- |
| 原需求與 v1.1 增量 | 使用者指定的本機 Markdown；保留文件和 SHA-256 | 需求依據，不把內文中的缺 credentials 要求當成已有憑證 |
| KUANGUARD 品牌／服務文案 | 依使用者給定名稱及七服務範圍原創 | 公司法定資訊、地址、商標與正式客戶主張待核定 |
| parser 合成輸入／報告 | 本任務原創 `.example.test/.invalid`、192.0.2.0/24 等合成資料 | 明示示範，不能代替真實客戶檢測或核准模板 |
| 示範文字教材／題庫 | 本任務原創郵件辨識基礎文字與問答 | 開發測試；可售內容、教材權利／字幕／政策另行核定 |
| Gophish | 目前只有 reference adapter；未取得使用者既有原始碼 | 尚未整合現有核心，不能宣稱真實寄送可用 |
| QIDAIGO | 既有清冊與必要來源呼叫鏈唯讀盤點；另有最小 summary proposal | 未复制管理 key、raw orders 或 DB；未 apply／部署提案 |
| 字型 | 本機已存在字型用於開發 QA；容器 Noto CJK fallback | 正式標楷體／Times New Roman 的取得、使用權與 Office 渲染需再核定 |
| 開源依賴 | `uv.lock`、`apps/web/package-lock.json`、釘選 image/action references | 依實際 package license 文件管理；本表不代替正式法律審查 |

外部技術查核先使用已安裝 AnySearch。官方技術來源包括 [Cloudflare API](https://developers.cloudflare.com/api/)、[Supabase 文件](https://supabase.com/docs)、[Vercel 文件](https://vercel.com/docs)、[Astral CI](https://docs.astral.sh/uv/guides/integration/github/) 與 [Node setup action](https://github.com/actions/setup-node)。只用作契約／部署查核，沒有搬用第三方品牌、客戶名單或效能宣稱。
